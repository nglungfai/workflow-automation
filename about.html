Measure the workflow, not the demo

How I work: research in, workflows out

Search agents sweep new papers, engineering write-ups, and practitioner guides, and each candidate faces one question: does this change how I build or operate? What survives goes into the AI Reading List with a note on how it applies, and the ideas that earn it become packaged skills and scheduled workflows.

Every entry on the reading list is rated against a published rubric, and the selection page walks through exactly how: an AI draft, an independent second review, automated checks, and author review where the ratings or flags call for it. The scheme is new and still being calibrated.

How this site is made

This site isn't written about agentic workflows. It is one. An agent drafts each page, cross-links it, and commits it. I review before anything publishes. A contract-check harness then tests every page against the rules it has to honor: links, navigation, footer, read-time honesty, homepage sync, and white-label hygiene.

A scheduled agent audits the site monthly for stale entries, broken links, and drifted claims, and files a report. It proposes; it never decides. Each reviewer correction and each pipeline failure is encoded back into the skills and memory the agents run on, so the same mistake doesn't ship twice.
